# Code of conduct

Davhaven adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies to everyone taking part in the project: in issues, pull requests, reviews,
discussions and any other project space, and when representing the project elsewhere.

## In short

- Be respectful and considerate; disagree about ideas, not people.
- Assume good intent and help newcomers find their way.
- No harassment, discrimination, personal attacks, sexualised language or imagery, or publishing others'
  private information.

## Reporting

Report unacceptable behaviour privately to the maintainer, [@rabitem](https://github.com/rabitem), using the contact
details on their GitHub profile. Please do not report it in a public issue or pull request. If the report concerns
a security issue, use the channel in [`SECURITY.md`](SECURITY.md) instead. Reports are handled confidentially.

## Enforcement

Maintainers review every report and decide on the response following the enforcement guidelines of the
Contributor Covenant: correction, warning, temporary ban or permanent ban, depending on the severity and
recurrence of the behaviour.
